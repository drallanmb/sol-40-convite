## Trust Boundaries

| Boundary | Description |
|---|---|
| Rendered DOM geometry → motion controller | Viewport, fonts and responsive layout supply target rectangles that must be validated before transforms. |
| User intent → playback control | Scroll, pointer, focus and navigation events may accelerate motion but must never be consumed. |
| Browser WAAPI/ResizeObserver → React lifecycle | Partial APIs, thrown methods and stale callbacks cannot be allowed to hold semantic UI state. |

## STRIDE Threat Register — ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-02-A | Denial of Service | WAAPI controller / `commitFinal` | high | mitigate | Idempotent final-state-first boundary; isolate every WAAPI call; focused throwing tests prove header/CTA/skip operable. |
| T-10-02-B | Tampering | DOMRect/resize-derived transforms | medium | mitigate | Clamp composition/progress, reject non-finite geometry, preserve generation, and fail open instead of emitting invalid transforms. |
| T-10-02-C | Denial of Service | full-viewport compositing | medium | mitigate | Animate only transform/opacity, bound layer count, stop loops in reduce, avoid per-frame React/layout and remove will-change after complete. |
| T-10-02-D | Elevation of Privilege | intent listeners over controls | high | mitigate | Passive/non-canceling listeners, no overlay target, skip outside inert, and tests prove the original action remains sovereign. |
