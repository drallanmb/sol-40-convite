## Planner assumptions and unresolved edge classification

This plan assumes the user’s Vercel and Convex sessions are already authenticated as stated in D-05. Codex conducts the consoles/CLI and pauses only for login, security confirmation, secure password entry, or a genuinely external account choice. No secret value may pass through plan text, shell arguments, logs, screenshots or committed evidence.

LAUNCH-03 and LAUNCH-04 remain spec-less/unresolved. The plan proves settings with names-only/live behavior and production with direct public evidence; it cannot prove the unavailable real list. That item remains pending for the independently resumable Plan 07-05 disclosure checkpoint.

Reversibility: linking/configuring environments is **costly** but reversible; deploy promotion and backup creation are **easy** to reverse/retain; secret generation is **costly** because rotation must be coordinated. No one-way door is crossed. If an external console adds a destructive/irreversible confirmation, stop at the console’s human confirmation rather than clicking automatically.

## Trust Boundaries

| Boundary | Untrusted side | Trusted side |
|---|---|---|
| Local repository -> Vercel project | wrong scope/project/link metadata | resolved repository/project identity |
| Vercel build -> Convex deployment | environment-scoped deploy key | matching Preview or Production backend |
| Operator input -> Convex env | password and target selection | secure input plus explicit `--prod` |
| Production deployment -> browser | public JS/SPA and Convex URL | expected commit, production backend and protected auth |
| Convex production -> backup artifact | real rows and file storage | completed ZIP outside git plus checksum only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-ENV-01 | Information disclosure | deploy/env configuration | high | mitigate | Names-only verification, secure secret entry, no values in args/logs/screenshots, and source scan before evidence commit. |
| T-07-ENV-02 | Tampering | Preview/Production isolation | high | mitigate | Distinct scoped keys, distinct deployment URLs/IDs, fictitious Preview write and Production non-contamination check. |
| T-07-DATA-01 | Information disclosure | backup | high | mitigate | Download outside repository, record only timestamp/deployment/checksum, and never inspect/commit row contents as evidence. |
| T-07-DATA-02 | Tampering | real production data | high | mitigate | Complete backup before any material write; no real import in this plan; disposable smoke cleans and verifies if used. |
| T-07-SMOKE-01 | Elevation of privilege | `.vercel.app` admin | high | mitigate | Pre-auth transport/DOM privacy check and functional login without recording credential. |
| T-07-COMPAT-01 | Denial of service | Convex deploy plus Vercel rollback | high | mitigate | Additive/backward-compatible Convex changes and separate healthy frontend/backend targets. |

Any open or failed high-severity threat blocks production promotion or completion.
