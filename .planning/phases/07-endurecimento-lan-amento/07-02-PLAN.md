## Planner assumptions and unresolved edge classification

LAUNCH-01, LAUNCH-02, LAUNCH-03 and LAUNCH-04 are spec-less. The deterministic edge fallback leaves physical interruption/concurrency and AA/mobile coverage unresolved; this plan therefore creates executable checks and explicit human backstops without converting them to silent green. It assumes the built SPA can use the existing non-secret `VITE_CONVEX_URL` for local browser preflight and that live targets will be supplied through `PLAYWRIGHT_BASE_URL`.

The initial context-only external-API detector returned false, but the final executable plans deterministically signal Vercel/Convex/Cloudflare API integration. `COVERAGE.md` therefore enumerates every in-scope capability and explicit opt-out. The schema gate does not apply: this repository uses Convex, while the configured schema detector targets Payload, Prisma, Drizzle, Supabase and TypeORM.

Reversibility: metadata/docs/tests are **easy**; evidence-driven UI/CSS fixes are **easy** when isolated; dependency/lockfile additions are **costly** but reversible. No one-way action occurs.

Canon referral: generic OWASP/accessibility compliance is covered by the security and WCAG gates; the bespoke evidence-honesty and non-exclusion prohibitions remain flagged.

## Trust Boundaries

| Boundary | Untrusted side | Trusted side |
|---|---|---|
| Built SPA -> browser test | route HTML, runtime requests, viewport states | deterministic release assertions |
| Anonymous `/admin` -> Convex transport | unauthenticated browser | status-only gate and no protected DTO |
| Operator docs -> production CLI | copied commands and environment selection | explicit `--prod`, names-only verification |
| Automated results -> launch evidence | emulator screenshots and runner reports | labeled evidence classes and pending manual backstops |
| Test artifacts -> repository | traces/screenshots/fixtures | failure-only capture with no secrets or real data |
