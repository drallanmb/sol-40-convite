## Planner assumptions and unresolved edge classification

Codex uses the already authenticated Cloudflare/Vercel sessions and pauses only for login, security confirmation or an external owner choice. Vercel-provided DNS targets are runtime facts and must be read from the actual project; no target is guessed in this plan. Existing nameservers are fixed.

The site can launch while independent Plans 07-05 (real list) and 07-06 (physical devices) remain pending. Neither is a sequential task in this core publication plan, so either follow-up can resume when its prerequisite becomes available. Physical tests do not block publication, while real-list review blocks only sending the invitation.

Reversibility: DNS record and Vercel domain changes are **costly** but reversible; release rollback drill is **costly** and reversible; sending the invitation is a **one-way** door. The executor must stop at the explicit owner checkpoint immediately before any invitation distribution; this plan never sends messages itself.
