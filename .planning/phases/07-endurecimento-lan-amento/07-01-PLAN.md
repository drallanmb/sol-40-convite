## Planner assumptions and unresolved edge classification

LAUNCH-03 is spec-less and therefore remains unclassified/unresolved. This plan assumes a maximum 1 MiB local file and 2,000 CSV records, UTF-8/BOM input, delimiter autodetection for comma/semicolon, 25-family/100-person server batches, and no raw-file persistence. These are flagged implementation backstops, not proof that the unavailable real list has been imported. Existing unrelated edits in `src/lib/phone.ts` and `src/lib/phone.test.ts` are read-only dependencies and must remain byte-preserved.

Reversibility: package/parser/UI additions are **easy** to revert; additive Convex API deployment is **costly** because older open clients may coexist but remains backward-compatible; real guest import is not performed in this plan. No one-way door is authorized.

Canon referral: generic injection/path-traversal and broad privacy compliance belong to `/gsd-secure-phase`; the product-specific non-overwrite, evidence privacy, and manual-workflow prohibitions above remain flagged here.

## Trust Boundaries

| Boundary | Untrusted side | Trusted side |
|---|---|---|
| CSV file -> browser preview | encoding, headers, quoted cells, names, phones, row count | bounded parser and explicit issue model |
| Browser preview -> Convex mutation | token, groups, source rows, names, phone, batch size | authorize-first server revalidation |
| Import writer -> RSVP tables | stale preview and concurrent owner changes | indexed logical-phone check plus canonical insert helper |
| Mutation results -> admin UI | partial/out-of-order/network results | command-owned sequential accumulator |
| Admin session loss -> import memory | File, preview and report containing guest data | synchronous sensitive-state clear |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-CSV-01 | Tampering | parser/grouping | high | mitigate | Bound bytes/rows, normalize exact headers, preserve strings, reject incompatible phone/family groups, and unit-test source-row reasons. |
| T-07-CSV-02 | Elevation of privilege | importFamilies | high | mitigate | Call requireAdminSession before reads, validate args/returns, cap batches, and matrix-test invalid sessions. |
| T-07-CSV-03 | Tampering | existing invitations | high | mitigate | Recheck all logical phone candidates and return existing_phone without patch/merge/delete. |
| T-07-CSV-04 | Repudiation | partial import report | medium | mitigate | Return stable created/ignored envelopes with sourceRows and retain confirmed batch results after transport failure. |
| T-07-CSV-05 | Information disclosure | browser/import state | high | mitigate | Never upload raw files; clear state on auth loss and assert DTO/report contains no token or internal secret. |
| T-07-CSV-06 | Denial of service | oversized CSV/batch | high | mitigate | Enforce 1 MiB/2,000 records client-side and 25 families/100 people server-side before writes. |

Any open or failed high-severity threat blocks this plan.
