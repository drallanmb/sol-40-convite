## Spacing Scale

Declared values (must be multiples of 4). Maps to the `--space-*` tokens already in `src/index.css`:

| Token | Value | Usage |
|-------|-------|-------|
| 2xs | 4px | Icon-to-label gaps, tight inline padding |
| xs | 8px | Compact element spacing (badge padding, gap between countdown label/value) |
| sm | 12px | Field gaps, dress-gallery grid gap |
| md | 16px | Default element spacing, card padding (mobile) |
| lg | 24px | Section-internal spacing, card padding (desktop) |
| xl | 32px | Layout gaps between stacked blocks |

Exceptions:
- **Section-level (page) padding does not use a fixed 48/64 token.** It uses the old project's responsive `clamp()` pattern (e.g. `clamp(80px, 10vw, 160px)` vertical, `clamp(24px, 7vw, 110px)` horizontal) so large sections (countdown, programa, traje, aracaju, footer) breathe on desktop without forcing excess whitespace on mobile. Translate with Tailwind arbitrary values (`py-[clamp(80px,10vw,160px)]`) — this is the one place utility classes intentionally diverge from a fixed token.
- **44px minimum touch target** on every tappable element (buttons, nav links, hamburger, "ver mapa"/"Abrir rota" links, guide/hotel card links) — already the pattern in `Button.tsx` (`min-h-[44px]`) and the old skip-link/menu-toggle. Carries forward LAUNCH-02's AA target into this phase rather than deferring it.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16–18px (`text-body`, fluid) | 400 (regular, `font-sans`) | 1.62 |
| Label | 13–15px (`text-caption`/`text-small`) | 700 (bold, `font-sans`, uppercase, `tracking-label` 0.1em) | 1.2 |
| Heading | 48–78px (`text-heading`, fluid) | 400 (regular, `font-serif`) | 1.02 |
| Display | 80–116px (`text-display`, fluid) | 400 (regular, `font-serif`, `tracking-display` −0.025em) | 0.86 |

**Exactly 2 weights, per contract: 400 (regular) and 700 (bold).** **[AUTO]** The old CSS used a stray 500/600 on a few "strong" labels (`dress-rules strong`, `hotel-list strong`). This phase collapses those into the **Heading** role instead — i.e. "Homens"/"Mulheres" in the traje section and each hotel name render at `font-serif` regular 400, `text-subheading` size (28px), colored `peach`/`coral` for emphasis — so weight alone never has to carry a third value. No visual loss: size + color already provide the emphasis those labels need.

Not used for nav links, body copy, card borders, or the topbar wordmark.

## Hero & Motion Spec (D-06/D-07/D-08 — prescriptive, not exploratory)

- **Sky/sun/horizon:** port the exact old gradients as Tailwind arbitrary-value/custom CSS (not achievable with plain utilities) — radial sun glow + 5-stop linear gradient (`#cf755f → #ed895e → #ed684a → #4b2937 → #1a3940`), sun as a `border-radius:50%` div with `box-shadow` glow, horizon as two stacked linear-gradient bands at `inset: 69% 0 0`. 1:1 with `globals.css` lines 187–191.
- **Palmeiras (D-07, new asset):** inline SVG, one per side, same footprint as the old CSS (`width 360 / height 600`, `bottom -130px`, `left -82px` / `right -82px` mirrored). Redraw as a real trunk + 6 fronds with a visible midrib line and asymmetric curvature between the two — not 6 identical rotated rectangles like the old CSS version. Fill `#291c25`, `drop-shadow(0 12px 30px rgba(18,15,22,.2))` preserved.
- **Mar (D-08, Claude's Discretion — auto-resolved to the CONTEXT-recommended option):**
  - **Layer 1 — waves:** 2–3 stacked SVG `<path>` bands under the horizon line, each tiled/looped via `translateX` `@keyframes` (`0% → -50%`, `linear`, `infinite`), staggered durations (22s / 30s / 38s) for a parallax feel, front wave more opaque than the back ones.
  - **Layer 2 — golden light path:** a soft vertical gradient trapezoid from the sun down to the bottom edge, shimmering via an opacity keyframe (`0.85 ↔ 1`, `3.5s ease-in-out infinite`) — not a hard-edged beam.
  - **`prefers-reduced-motion: reduce`:** every keyframe above becomes `animation: none`; the waves and light path stay visible as static art (last-frame equivalent), motion is removed but the visual richness is not. This is a hard requirement (D-08), not optional polish.
- **Countdown rail (D-11):** `.countdown-rail`/`.countdown-compact` behavior ports as-is — hidden by default, slides in (`translateY(-6px) → 0`, opacity 0→1) once scroll passes the bottom of the countdown section, using the existing `--z-sticky` token. Topbar itself gains a translucent-cream + blur backdrop past `scrollY > 12px` (already partially present in `Shell.tsx`'s sticky header, needs the scroll-state class added).
