## Security baseline

ASVS level 1 is active. Blocking threshold is **high**.

## Assets/boundaries

| Boundary | Untrusted side | Trusted side |
|----------|----------------|--------------|
| Selected file -> Canvas/preview/upload | Huge/malformed/unsupported photo | bounded decode, canonical JPEG, cleanup |
| Controlled text -> Convex mutation/DOM | Oversized/control/markup-looking text | shared bound, server authority, React text |
| Browser state -> public upload protocol | retries, double click, stale transport | busy guard + reducer + backend idempotency |
| localStorage/component memory -> requests | malformed fairness key/capability leakage | canonical key, in-memory capability, no logs/URL |
| Backend status -> success/reset | processing/rejection mistaken for success | accepted-only transition |
