## Security baseline

ASVS level 1 is active. Blocking threshold is **high**; every high row must have green proof.

## Assets/boundaries

| Boundary | High risk | Control |
|----------|-----------|---------|
| Anonymous request -> upload URL | Storage-cost reservation abuse | Device + global checks before URL |
| Storage POST -> pending post | MIME spoof/oversize/active bytes | Metadata plus real-byte action |
| Capability/retry -> reservation state | Replay, race, duplicate post | Hash, expiry, ownership, idempotent transaction |
| Database -> public gallery/status | Moderation/private metadata leak | Approved-only/minimal and scoped projections |
| Storage lifecycle -> cleanup | Orphans or deletion of live blobs | age threshold plus all-owner checks |

## Threat register

| ID | Threat | Severity | Mitigation | Blocking proof |
|----|--------|----------|------------|----------------|
| T-05-02-A | Attackers reserve/upload at platform cost before throttling. | high | Check and consume global/device buckets before URL generation. | Parallel N-1/N/N+1 tests assert zero URL/reservation on denial. |
| T-05-02-B | Fake MIME, oversized, malformed, HEIC, or active file creates a post. | high | `_storage` bound then Blob magic-byte agreement before insert. | Complete binary/metadata matrix and deletion assertions. |
| T-05-02-C | Action interruption/replay or parallel retry creates duplicates. | high | Single owner/state, cooldown requeue, idempotent final transaction. | Concurrent claim/action/finalize tests assert one post ID/count. |
| T-05-02-D | Invalid/orphan storage accumulates or cleanup deletes live media. | high | Reject deletion, exact expiry, old-only paginated sweep, all-owner indexes. | -1/at/+1, owned/unowned/race/repeat tests. |
| T-05-02-E | Pending/hidden content, URL, storage ID, capability, or moderation metadata leaks. | high | Backend-approved filter before URL; scoped minimal status; explicit return validators. | URL spy, recursive forbidden-key, A/B capability tests. |
