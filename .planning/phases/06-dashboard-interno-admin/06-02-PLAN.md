## Security baseline

OWASP ASVS level 1 is active. Blocking threshold is **high**; any open or failed high-severity threat blocks completion.

`security_standard: OWASP ASVS` · `asvs_level: 1` · `block_on: high`

## Trust Boundaries

| Boundary | Untrusted side | Trusted side |
|----------|----------------|--------------|
| React route/visibility -> protected hooks | Direct deep links and client state | Authoritative session gate plus server guard |
| Browser token -> `adminOverview.get` | Forged, expired, or revoked capability | `requireAdminSession` before any domain read |
| RSVP/post/wine source rows -> overview UI | Mixed statuses and reconnect timing | Reactive purpose-built count DTO |
| Navigation/card interaction -> route state | Keyboard, touch, and URL query input | Canonical routes, semantic links, validated filters |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06 | Information disclosure | pre-auth React subscriptions | high | mitigate | Protected components and hooks do not mount until authoritative status is valid; logged-out transport inspection proves no domain payload. |
| T-06-07 | Elevation of privilege | nested admin routes / `adminOverview.get` | high | mitigate | Every protected query re-authorizes server-side; deep links never weaken the gate. |
| T-06-08 | Information disclosure | reconnect and auth revocation | high | mitigate | Any authorization failure clears the protected tree immediately; only authorized transient reconnect may retain labeled data. |
| T-06-09 | Tampering | overview aggregates and badges | medium | mitigate | Count families independently from people/status rows and test 0 families versus 1 zero-person family plus zero/one/many/mixed-family attendance cases without materialized client snapshots. |
| T-06-10 | Spoofing | navigation/action affordances | medium | mitigate | Use semantic links/navigation, visible focus, one active navigation instance, explicit labels, and 44px targets. |
</threat_model>
