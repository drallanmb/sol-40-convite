## Planner assumptions and unresolved edge classification

The deterministic specless probe classified ADMIN-01 as `unclassified/unresolved`. This plan does not treat that as empty coverage. It assumes the requirement means a single shared owner credential, a hash-only opaque capability session, absolute seven-day TTL, indexed revocation, uniform denial, and no protected reads before authorization. These assumptions are flagged until implementation evidence and owner UAT confirm them.

Prohibition recall retained only the two product-specific privacy/scope constraints in frontmatter. Generic injection, brute-force, secret handling, and OWASP concerns are canon and route to `/gsd-secure-phase` plus lint/security review rather than being minted as bespoke prohibitions.

## Trust Boundaries

| Boundary | Untrusted side | Trusted side |
|----------|----------------|--------------|
| Anonymous browser -> `adminAuth.login/getSessionStatus/logout` | Password and opaque-token input | Rate limit, canonical validation, hash-only lookup, uniform public result |
| Raw browser capability -> `adminSessions` | Replayable client-held token | SHA-256 indexed row with absolute server expiry |
| React route/session state -> protected Convex APIs | Client visibility and URL are bypassable | `requireAdminSession` on every protected server entry point |
| Convex scheduler -> session row | Delayed or duplicated expiry job | Expected-id/expiry checked idempotent deletion |
| One browser tab -> another tab | Stale persisted capability and protected drafts | Storage-event fail-closed clearing |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Spoofing / Denial of service | `adminAuth.login` | high | mitigate | Globally rate-limit before insertion, compare fixed-length digests with constant work, and return one invalid-credentials shape for wrong or missing configuration. |
| T-06-02 | Information disclosure | admin capability/session storage | high | mitigate | Require canonical 32-byte entropy, persist only SHA-256, never store password/DTO/hash client-side, and enforce absolute expiry plus explicit deletion. |
| T-06-03 | Spoofing | scheduled session expiry | high | mitigate | Guard every call with `now < expiresAt` and schedule expected-expiry idempotent deletion so time becomes a reactive database change. |
| T-06-04 | Elevation of privilege | protected admin endpoints | high | mitigate | Never trust the React gate; authorization-matrix tests require `requireAdminSession` before every protected read/write. |
| T-06-05 | Information disclosure | cross-tab cache and drafts | high | mitigate | Storage removal, server revocation, logout, and local deadline immediately unmount protected data and clear drafts in every tab. |
</threat_model>
