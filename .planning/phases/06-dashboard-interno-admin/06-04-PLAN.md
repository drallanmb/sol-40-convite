## Planner assumptions and unresolved edge classification

Without a phase SPEC, ADMIN-05/06 remain unresolved. This plan assumes URL-owned status tabs, monotonic per-record revisions, server timestamps, exact legal transition graphs, eight-second conditional undo, and no public attribution. Each assumption has backend, pure-client, build, and live-browser evidence; none is silently dismissed.

Prohibition recall retains the product-specific privacy, concurrent-decision safety, and truthful-state constraints. Generic authorization/injection/storage security remains canon for `/gsd-secure-phase`.

## Trust Boundaries

| Boundary | Untrusted side | Trusted side |
|----------|----------------|--------------|
| Admin browser -> post moderation API | Post id, status, revision, undo command | Guarded closed transition state machine |
| Admin browser -> wine gift API | Wine id, presenter, expected `updatedAt` | Guarded shared atomic gift transition |
| Protected post row -> storage URL/admin card | Pending/hidden metadata and media | Authorization before row projection or URL generation |
| Protected wine row -> public catalog | Presenter, timestamp, revision | Narrow public status-only DTO |
| Internal smoke helper -> live domain rows | Disposable fixture mutation and failures | Bounded snapshot plus `finally` restoration through the same transition helper |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-17 | Information disclosure | `adminPosts.listByStatus` and storage URLs | high | mitigate | Authorize before reading protected metadata or generating URLs; keep `posts.listApproved` unchanged and minimal. |
| T-06-18 | Tampering | moderation transition | high | mitigate | Enforce a closed transition map and transactionally compare/increment `moderationRevision`. |
| T-06-19 | Tampering | moderation undo | high | mitigate | Require exact action-produced status/revision so stale or ABA undo cannot overwrite a later decision. |
| T-06-20 | Tampering | wine gift state | high | mitigate | Route admin and smoke writers through one atomic helper using existing monotonic `updatedAt`; enforce complete available/gifted discriminated states. |
| T-06-21 | Information disclosure | public post/wine projections | high | mitigate | Regression-test approved-only posts and public wines without `giftedBy`, `giftedAt`, or revision. |
| T-06-22 | Repudiation / Tampering | duplicate submit and concurrent dialog | high | mitigate | Disable only the affected command, require expected revision, return conflict without false success, and retain current remote state. |
</threat_model>
