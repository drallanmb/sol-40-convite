## Trust Boundaries

| Boundary | Untrusted side | Trusted side |
|----------|----------------|--------------|
| Admin browser -> family/person mutations | IDs, patches, phone, attendance, expected revision | Guarded ownership, validation, and one transaction |
| Changed family phone -> public RSVP sessions | Superseded browser capabilities | Indexed transactional revocation before new phone is authoritative |
| Reactive family snapshot -> local dirty draft | Stale local edits from either owner | Explicit revision conflict and review |
| Family deletion -> guests/sessions | Partial or oversized cascade request | Bounded preflight and atomic indexed deletion |
| Admin family DTO -> public RSVP surface | Internal IDs/contact/revision | Separate guarded projection; public DTO unchanged |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-11 | Elevation of privilege | family/person CRUD | high | mitigate | Authorize first, verify person ownership and family revision in the same transaction, and matrix-test every endpoint. |
| T-06-12 | Spoofing | phone-based RSVP capability | high | mitigate | On logical phone change, delete every `rsvpSessions.by_rsvp` row before patching the normalized phone. |
| T-06-13 | Tampering | public/admin family revision line and expanded editor | high | mitigate | Route public saveResponses and every production admin writer through shared max(now,current+1), require expected `updatedAt` for admin commands, and return conflict with no write when a public or admin save advances the remote revision. |
| T-06-14 | Tampering | family cascade deletion | high | mitigate | Preflight bounded child/session counts and delete indexed guests/sessions plus family in one Convex transaction. |
| T-06-15 | Spoofing | new guest `publicRef` | high | mitigate | Generate a bounded collision-checked opaque ref only for the new person and never recompute existing refs. |
| T-06-16 | Information disclosure | admin/public RSVP projections | high | mitigate | Keep a dedicated guarded admin DTO and regression-test the unchanged narrow public `getCurrent` result. |
</threat_model>
