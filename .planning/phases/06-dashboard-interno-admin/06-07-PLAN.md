<interfaces>
Current defect:
- `busyFamily`, `busyPost`, and `busyWine` are each `string | null`.
- Every operation executes an unconditional `setBusy*(null)` in `finally`.
- Different records are intentionally allowed to mutate concurrently.

Required transition contract:
- begin(id) succeeds once and synchronously marks only id pending.
- begin(id) while id is pending returns false and invokes no mutation.
- settle(id) removes only id, preserving every other pending id.
- membership drives the affected row/dialog's `disabled` and `aria-busy`.
</interfaces>

## Trust Boundaries

| Boundary | Untrusted side | Trusted side |
|---|---|---|
| Repeated UI activation -> Convex mutation | Double click, Enter/click race, stale closure | Synchronous per-id duplicate guard |
| Concurrent promise completion -> React state | Arbitrary A/B completion order | Functional removal of only completed id |
| Reactive row/dialog -> feedback | Newer command or remote revision | Command-scoped completion and review state |
| Test dependency -> repository | npm package and lockfile | Exact pin, provenance/integrity inspection, dev-only usage |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-41 | Denial of service | duplicate submit | medium | mitigate | Ref-backed synchronous membership guard blocks a second call for the same id before mutation invocation. |
| T-06-42 | Tampering | out-of-order completion | medium | mitigate | Functional Set/map settlement removes only the matching id; command-scoped state prevents stale dialog cleanup. |
| T-06-43 | Repudiation | misleading busy/feedback state | medium | mitigate | `aria-busy`, disabled state, and feedback derive from exact pending command membership and deterministic A/B tests. |
| T-06-44 | Information disclosure | pending state on auth loss | high | mitigate | Existing protected-state clear event resets pending/dialog state; persist no ids, drafts, or DTOs. |
| T-06-45 | Supply chain | jsdom dev dependency | high | mitigate | Verify official npm metadata/repository/integrity, install an exact version, commit lockfile, run security/slop checks, and keep import test-only. |
