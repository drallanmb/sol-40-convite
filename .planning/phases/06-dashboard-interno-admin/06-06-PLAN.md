## Planner assumptions and unresolved edge classification

Because no plain phase SPEC exists, ADMIN-04 remains probe-classified unclassified/unresolved. This plan closes only the concrete availability/revocation predicate in `06-VERIFICATION.md` and `06-REVIEW.md`. The additive generation seam is necessary: Convex mutations are atomic but a permanently unbounded number of historical row deletions cannot be made a safe prerequisite for the phone patch. Generation invalidation makes authorization immediate; scheduled pages make physical cleanup finite and observable.

## Trust Boundaries

| Boundary | Untrusted side | Trusted side |
|---|---|---|
| Owner browser -> update/delete mutation | Token, family id, phone patch, stale expected revision | Admin guard, logical phone normalization, optimistic revision |
| Phone change -> old public capabilities | Any number of hashed historical sessions | Atomic invitation generation advance |
| Deleted invitation -> orphan session rows | Delayed physical deletion | Missing-family denial plus bounded internal purge |
| Purge command -> family session index | Retried/reordered cursor and concurrent later-generation sessions | Exact rsvpId scope plus tagged immutable cleanup command |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-31 | Denial of service | updateFamily/removeFamily | high | mitigate | Remove fixed-count refusal; immediate generation/missing-family denial is independent of row count. |
| T-06-32 | Spoofing | pre-change RSVP capability | high | mitigate | Atomically advance generation with logical phone patch; verify representative and exhaustive old tokens fail before purge. |
| T-06-33 | Tampering | stale owner edit | high | mitigate | Preserve expectedUpdatedAt and normalized uniqueness; no generation bump or cleanup schedule on conflict/invalid input. |
| T-06-34 | Denial of service | cascade cleanup | high | mitigate | Scan/delete fixed pages, carry cursor and the exact tagged cleanup command, schedule continuation, and prove >128 completion/idempotency. |
| T-06-35 | Tampering | delayed/reordered phone-change purge | high | mitigate | `olderThanGeneration` deletes only `legacyAwareGeneration < commandGeneration`; equal and later generations survive even when older commands arrive after later issuance. |
| T-06-37 | Tampering | cleanup mode confusion | high | mitigate | A required discriminated command separates `olderThanGeneration` from `deleteAll`; only family deletion emits `deleteAll`. |
| T-06-36 | Information disclosure | smoke/purge results | high | mitigate | Internal-only commands return counts/state, never tokens, hashes, phones, or protected family DTOs. |
